# 归档

## generate-blog.py.legacy

原来的博客生成脚本（生成 29 篇文章）。**已停用**，原因：

- 它会把 `blog/*.html` 整篇覆盖，2026-11 之后手工加进每篇的东西会被抹掉：
  - 相关阅读（每篇 3 条内链）与面包屑结构化数据
  - 正文排版样式（h2/p/li 间距）
  - 百度自动推送脚本
  - canonical / 站内链接的净地址修正
- 文章数已经从 29 变成 31，脚本里的清单也不全了。

现在改文章请直接编辑 `blog/*.html`。新增文章时可以复制任意一篇改内容，
再更新 `sitemap.xml` 和 `/blog/` 列表页。
